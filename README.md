# 🚀 Space Exploration Recruitment Landing Page

This project is a simple, responsive landing page inviting visitors to apply to join a space exploration mission. The webpage was built using **HTML and CSS**, with a focus on layout, styling, accessibility, and version control best practices.

---

## 🌌 Project Overview

The landing page includes:

- A hero section with a space-themed **background image**
- Clear headline and call-to-action messaging
- An **Apply Now** button for the user action
- Legible and accessible typography and color contrast

This project demonstrates foundational front-end development skills while practicing structured page layout and component styling.

## 🎨 Key Front-End Concepts Learned

### **1. File Paths**
- `./images/` → Same directory level  
- `../images/` → Move up a folder  
- `../../images/` → Move up two levels  

### **2. Images & Accessibility**
- Added `alt` text for screen readers and SEO
- Kept alt descriptions under ~125 characters

### **3. CSS Classes & Utility Styling**
- Used reusable classes to keep styles modular and efficient
- Example:
```css
.avatar {
  width: 150px;
}
````

### **4. Flexbox Layout**

* Used `display: flex;` to align direct child elements
* Used `justify-content: space-around;` for spacing

### **5. Centering Content**

```css
margin: 0 auto;
```

to center containers like cards on the page

### **6. Fonts**

* Implemented **Google Fonts** via `<link>` in the HTML `<head>`
* Styled fonts per element (`body`, `h1`, buttons, etc.)
